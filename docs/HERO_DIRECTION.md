## Tokens

- Ground: #07080B, shared with the surrounding portfolio.
- Type: #EFF2F6, with #ADB6C2 for secondary reading.
- Page accent: #546BF3, with #A9B7FF for accessible accent text.
- Material midtone: #677692, used only inside the dimensional letterform.
- Space Grotesk 500: headline, with close optical spacing and explicit line breaks.
- Inter: identity, role, links and controls. No additional font download.
- Desktop: left-aligned type and asymmetric foreground object, not a card grid.
- Phone: type first, smaller object second, full-size readable actions below.

One expressive object, quiet surrounding typography. No all-caps metadata, status
pills, decorative statistics, repeated arrows, scene switcher, or ambient movement.
The structure toggle is user-triggered, keyboard accessible, and reduced-motion safe.
No edits to either protected stickman component or their root tokens.
