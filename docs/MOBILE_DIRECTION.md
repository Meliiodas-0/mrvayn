# Mobile v6.8: carry the sculpture into the work

The owner finds the phone experience less compelling than the approved desktop.
This was prepared as a local mobile refinement of v6.7, not a new art direction.
The owner subsequently approved publication on 8 September 2026 for phone review.

## Plan, before implementation

Retain ground #07080B, lacquer #23252A, primary #EFF2F6, body #ADB6C2,
metadata #96A0AF and focus #A9B7FF. Keep the current Inter reading voice and
Barlow Condensed headings. Preserve the desktop composition and all project copy.

One expressive idea: the six-letter sculpture becomes a continuous mobile thread.
Keep the readable MR / VA / YN opening, then fan the letters to the edges. An
oversized cropped letter changes with the projects and sections, rolling gently
as the reader scrolls. Its 18% reading opacity keeps text dominant. No idle loop,
scroll lock, new blank runway, horizontal page navigation or decorative UI cards.

```text
Opening                 Work                    Later work / sections
   M   R                Selected work           Antarya
   V   A                (cropped M at edge)      (R enters opposite edge)
   Y   N                [edge-to-edge film]     [edge-to-edge image]
identity / View work    contribution / links     contribution / links
```

Mobile chapter anchors: Work, Antarya, SAO-X, About, Skills and Journey. This gives
individual selected projects their own transitions on the longer phone layout.
Contact clears the sculpture. Reverse scrolling must retrace exactly.

Allow a direct, restrained finger response in the hero using passive pointer
listeners. Release/cancel returns to rest; native vertical scrolling takes priority.
Never intercept links or menus. Keep reduced motion as a still, non-pinned hero.

Use full-bleed selected-project media on phone, with captions and text inside the
reading gutter. Improve the small hero identity's legibility. Keep the remaining
layout quiet so the sculpture and real work carry the visual weight.

Review against brief: dark and subtle, original MRVAYN character, no game background,
no superiority claims, no change to either protected stickman or the desktop poses.
Expose mobile scale, turn and touch strength in the existing dev-only DialKit panel.
Verify phone scroll states, narrow overflow, menu and media, desktop regression,
continuous/reversible poses, readable contrast, TypeScript, lint and production build.
