# Hero v6.4, dark studio index

Historical direction. Superseded by `HERO_SCULPTURE_DIRECTION.md` after the owner
selected Maxime Veilleux's sculptural concept on 7 September 2026.

The owner explicitly wants dark and subtle. Code / Play and the cobalt field were
rejected as childish. Preserve the two stickman features; remove novelty typography
and interactions from the portfolio itself.

## Compare before building

Recolouring the kinetic poster would preserve the rejected premise. Another object
beside a marketing headline would repeat the rejected silver V. Instead, introduce
the person and expose the substance of three real projects.

```text
Aayush   / MrVayn                 Selected projects
                                 Cricket Broadcast Lab
Unreal Engine &                   SAO-X

short introduction               selected contribution
studio / work / contact           Open project
```

Phones read identity, role, introduction and actions, then the same compact project
selector. No image, video or decorative background; no invented terminal or metrics.

The owner identifies Antarya as a company, not a project, and has excluded it from
the hero. The hero index contains Cricket Broadcast Lab, SAO-X and MagViz.

## Tokens and principles

- Ground #07080B, subtle active surface #101318.
- Primary type #EFF2F6.
- Body #ADB6C2.
- Quiet type #828D9C.
- Focus and active accent #A9B7FF, used sparingly.
- Space Grotesk 500 for the name and project titles; Inter for reading and controls.
  Both already exist; do not replace the protected font variables.
- Left-aligned name and concise identity; compact right-hand project index.
- The name is the headline. No slogan, superiority claim, code pun, or extra mascot.
- Selecting a real project reveals its contribution and direct in-page destination.
  The only motion is a short, non-bouncing selection indicator, with reduced motion.
- Keep the native content visible, keyboard support complete, and phone scrolling native.
