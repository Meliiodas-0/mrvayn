# Hero v6.3, Code and Play

Historical and rejected as childish. The current direction is dark and subtle;
see `HERO_STUDIO_DIRECTION.md`. Do not restore this treatment.

The owner found the silver V and black two-column opening dull. The follow-up asks
for a decent, interactive presentation that demonstrates technical care without
claiming superiority. The cursor enemies and cinematic remain protected.

## Compare

The rejected composition isolates a static object from its message:

```text
headline                         silver V
role / actions                   structure control
```

Adding an animated object would preserve the same split. Instead, make the lettering
the object visitors can manipulate. Use a single colour field, not another scene.

```text
Aayush / MrVayn                 actual role and studio

 C O D E
                    &
                         P L A Y

drag / tap; reset                       work / contact
```

Phones keep the diagonal composition at a smaller scale, with tapping instead of
dragging so the letters never trap vertical scrolling.

## Visual tokens

- Cobalt field: #3D50DB.
- Letter faces and primary reading: #F4F6FF.
- Extruded edges: #1F2B83.
- Secondary reading on cobalt: #DFE5FF.
- Ink actions and surrounding page: #07080B.
- Inter 900 for dimensional lettering; Inter 400/500 for reading. Use the existing
  variable font, not an extra download. Existing section heading fonts are unchanged.

Left-aligned identity, right-aligned desktop credentials, diagonally offset words.
Both words share weight and colour. The uppercase letters are the artwork, not
decorative metadata. No claim of being the best, fabricated metrics, game background,
card grid, ambient particle system, shader blob, or extra mascot.

The expressive choice is the type. Quiet copy and controls support it. Desktop
letters drag with bounded travel and a spring return; tapping or keyboard activation
tilts a letter. Reset restores the composition. Reduced motion bypasses the spring.
Expose spring feel in the existing development-only tuning panel and retain stable
production defaults. No idle animation loop or input listeners in protected files.
